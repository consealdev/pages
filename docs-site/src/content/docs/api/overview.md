The contract between the client's [sync](/docs/sync/overview/) calls and a backend is an OpenAPI description of the sync
and circle routes. It lives in the [`spec/` folder of the conseal repository](https://github.com/consealdev/conseal/tree/main/spec)
under the MIT license, and `ConsealDev.Conseal` and any other backend are built to it.
