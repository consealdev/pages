`@consealdev/conseal/ui` has the screens of the [circle ceremony](/docs/concepts/circle/) as Lit components over
`CircleClient`: the places where the user sees a code and confirms that it matches. They need `lit` and a browser.

The screens show the code and ask the user to confirm it, which a join needs on both devices before a key moves.
