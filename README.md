# conseal.dev

The pages of [conseal.dev](https://conseal.dev), the site of [conseal](https://github.com/consealdev/conseal).

| Folder | Holds |
|---|---|
| `www/` | The site: the home page and API reference, the demo, the threat model, and the usage docs in `usage/` |
| `landing/` | A placeholder landing page, not served |

`www/` is the site as conseal v0.6.0 deployed it. The demo runs on that version's browser builds, `assets/conseal.js` and `assets/bip39.js`, which are committed here.

Nothing deploys from this repo yet: conseal.dev still serves the pages of the v0.6.0 release. To view them locally, serve `www/` with any static file server.
